# Milestone 7: Figure Board

Implemented:

- Page format model with physical-unit to pixel conversion.
- Figure board model with panel placeholders, margins, gutters, and journal-preset field.
- Dynamic grid panel generation.
- Divider movement primitive for adjacent panels.
- Figure Board workspace for creating grid boards and assigning imported sources.

Known limitations:

- Drag handles and PowerPoint-style crop editing are not interactive yet.
- Collision avoidance is deferred to the rendering/export layer.
