# BioPic LM 0.1.0 Beta 1

SPDX-License-Identifier: GPL-3.0-or-later

BioPic LM 0.1.0 beta 1 is a pre-release build intended for early testing.

## Known Limitations

- Stack from Video is experimental and not fully tested.
- Stitch Images is experimental and not fully tested.
- Some image-editing tools and UI workflows may still contain bugs.
- Local user presets are not automatically included in source uploads or binary
  releases. Presets must be saved in a project file or exported and committed as
  explicit data files before they are distributed.

## Recommended GitHub Release Setting

When publishing this build on GitHub, mark the release as:

- `Pre-release`

Use a tag such as:

```text
v0.1.0-beta.1
```
