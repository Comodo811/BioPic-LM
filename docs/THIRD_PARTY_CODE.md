No third-party source code has been copied or adapted into BioPic LM. BioPic LM
currently integrates GIMP/Krita through a lossless external-editor round trip
implemented in `src/biopic/integrations/gpl_editors.py`.

Reference projects:

- GIMP: https://gitlab.gnome.org/GNOME/gimp
- GIMP GitHub mirror: https://github.com/GNOME/gimp
- Krita: https://invent.kde.org/graphics/krita
- RawTherapee: https://github.com/RawTherapee/RawTherapee

If code is copied or adapted later, record the upstream project, file path,
commit hash, copyright holder, license, local path, modifications, and
modification date before committing it.
