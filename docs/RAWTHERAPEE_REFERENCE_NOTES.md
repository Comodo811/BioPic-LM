# RawTherapee Reference Notes

SPDX-License-Identifier: GPL-3.0-or-later

BioPic LM currently uses RawTherapee as a design and parameter reference only. No
RawTherapee source file or asset has been copied or adapted.

Relevant upstream areas that may be useful as behavior references:

- `rtengine` processing modules for white balance, tone curves, denoise,
  high-pass/detail, wavelet, local contrast, and deconvolution behavior.
- `rtgui` tool panels for correction-module UI behavior.
