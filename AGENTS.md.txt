# Biopic repository instructions

## Primary constraints

- Treat preservation of scientific image data as critical.
- Never silently reduce bit depth, resolution, metadata or colour information.
- Do not modify user files during an audit.
- Do not change algorithms unless explicitly requested.
- Do not classify code as dead solely from text search.
- Trace GUI callbacks, registries, reflection and plugin loading before declaring
  anything unused.
- All performance claims must be labelled as measured or inferred.
- All security findings must include an attack scenario and affected boundary.
- Prefer small, testable changes over broad rewrites.

## Review output

Every finding must contain:

- unique ID;
- category;
- severity;
- confidence;
- affected files and symbols;
- evidence;
- practical consequence;
- reproduction or validation method;
- recommended fix;
- estimated effort;
- possible regression risk.
